💧 Nappe Phréatique EC7

Cas 0 — Zw ≥ Df+B → aucune influence. Rw1=Rw2=1
Cas 1 — Zw ≤ Df → nappe au-dessus. Rw1=0.5(1+Zw/Df), Rw2=0.5
Cas 2 — Df < Zw < Df+B → nappe dans zone B. Rw1=1, Rw2=0.5(1+zw2/B)
